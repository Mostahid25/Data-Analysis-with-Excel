
# 🏨 Airbnb Dashboard 2024 – Excel Project

This project presents a comprehensive Excel dashboard built using Airbnb listing data for the year 2024. It is designed to provide insights into listing prices, host performance, room types, and customer review patterns.

## 📌 Key Metrics:
- **Total Listings:** 86,358  
- **Average Price:** US$62  
- **Total Reviews:** 28,032  
- **Average Review Rating:** ★★★☆☆ (3/5)  
- **Price Range:** US$50 – US$1200  

## 📊 Dashboard Highlights:
- **Top 10 Costly and Cheapest Listings:** Visualized using bar charts to show extremes in listing prices.
- **Price vs Service Fee Comparison:** Compares average prices and associated service fees across room types.
- **Top 10 Most Rated Hosts:** Identifies hosts with the highest number of reviews.
- **Most Active Listings:** Line chart showing the most frequently listed properties.
- **Cancellation Policy Breakdown:** Donut chart showing distribution of flexible, moderate, and strict policies.
- **Room Type Filter:** Interactive slicer to filter the dashboard by room type (Entire home, Private room, Hotel room, Shared room).
- **Host Type Analysis:** Compares average prices between verified and unverified hosts.
